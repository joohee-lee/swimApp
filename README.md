# 나만의 수영일기 웹 앱 만들기

🏊‍♂️ 수영일기 앱 필수 기능 (MVP)
수영 기록: 날짜, 수영장 이름, 총 거리(m), 운동 시간
수영 영법 체크: 평형, 자유형, 배영, 접영 등 
오늘 연습한 영법 기록
오늘의 일기: 자유롭게 남기는 한 줄 감상평이나 팁

🛠️ 


1. 빈 폴더 생성 및 클로드 코드 실행
PC에 빈 폴더를 하나 만듭니다 브런치 가이드.
터미널(또는 명령 프롬프트)에서 해당 폴더로 이동한 뒤 클로드 코드를 실행합니다.

2. 첫 번째 프롬프트 입력 (초기 세팅 요청)
코딩을 모르더라도 클로드에게 내가 원하는 앱을 구체적으로 설명해주세요 위키독스 가이드.
"수영한 날짜, 수영장 이름, 총 거리(m), 오늘 연습한 영법(체크박스), 짧은 일기를 작성하고 저장할 수 있는 기능이 필요해. 화면은 깔끔하고 직관적인 디자인이었으면 좋겠어."

3. 앱 미리보기 및 피드백 
클로드가 코드를 다 짜주면 브라우저에서 열어보며 테스트합니다.
"수영장 이름 입력칸 아래에 즐겨찾는 수영장을 선택할 수 있는 버튼을 추가해줘."
"저장 버튼을 누르면 아래에 오늘 기록된 수영일기 목록이 카드로 보이게 해줘."

4. 완성 및 웹에 배포하기
완성된 앱은 넷플라이파이나 깃허브 페이지를 이용해 무료로 인터넷에 배포하고 스마트폰 홈 화면에 추가해 사용할 수 있습니다.

# swimApp v01 Plan

## localStorage 구조

### 키 목록

| 키 | 역할 | 형식 |
|---|---|---|
| `swim_records` | 수영 기록 전체 | `Array<Record>` |
| `swim_favorites` | 자주 쓰는 수영장 이름 | `Array<string>` (최대 5개) |

### 데이터 흐름

#### 기록 저장/불러오기
- **`load()`** (app.js:12) — `swim_records` 읽어서 배열 반환. 없으면 빈 배열.
- **`save(records)`** (app.js:16) — 배열 전체를 JSON으로 덮어씀.
- 폼 제출 시 (app.js:86~104): 새 기록을 `unshift`로 맨 앞에 추가 후 저장.
- 삭제 시 (app.js:77~84): `splice`로 해당 인덱스 제거 후 저장.

#### 즐겨찾기 (수영장 이름)
- **`loadFavorites()`** / **`saveFavorite(name)`** (app.js:20~31) — 중복 없이 최신 5개 유지.
- 저장 시 `unshift`로 맨 앞 추가 후 `.slice(0, 5)`로 잘라냄.
- 버튼 클릭 시 해당 이름이 pool 입력칸에 자동 채워짐 (app.js:40~44).

### Record 객체 구조

```js
{
  date: "2026-05-20",        // 날짜
  pool: "올림픽수영장",       // 수영장 이름
  distance: "1500",          // 거리 (m)
  duration: "45",            // 시간 (분)
  strokes: ["자유형", "배영"], // 영법 (체크박스)
  diary: "오늘 컨디션 좋았다"  // 메모
}
```
